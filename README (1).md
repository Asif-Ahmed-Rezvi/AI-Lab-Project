# Flight Route Optimization: A* vs. DFS

A comparative Artificial Intelligence Lab project that applies **A\*** (informed search) and **Depth-First Search (DFS)** (uninformed search) to a global flight-route network. The experiment searches for a route from **Dhaka, Bangladesh (DAC)** to **Frankfurt, Germany (FRA)** using airport and airline-route data from OpenFlights.

## Project Overview

The project models the global flight network as a directed graph:

- **Nodes:** Airports with geographic coordinates and identifying information.
- **Edges:** Directed flight connections between airports.
- **Start:** Hazrat Shahjalal International Airport, Dhaka (`DAC`, airport ID `3076`).
- **Goal:** Frankfurt am Main Airport (`FRA`, airport ID `340`).

The notebook compares how an uninformed search explores the network against a heuristic-guided search.

## Algorithms and Approach

### Depth-First Search (DFS)

- Uses a LIFO stack to explore one branch deeply before backtracking.
- Tracks the current path to avoid cycles.
- Uses a maximum depth of 12 to bound the search.
- Does not use geographic information to prioritize promising routes.

### A* Search

A* prioritizes states using:

\[
f(n) = g(n) + h(n)
\]

where:

- `g(n)` is the accumulated flight distance from Dhaka to the current airport.
- `h(n)` is the estimated remaining distance from the current airport to Frankfurt.
- `f(n)` is the estimated total route distance through the current airport.

The implementation uses a min-heap priority queue and tracks the best known accumulated cost for each airport.

### Geographic Distance: Haversine Formula

The notebook calculates great-circle distances using the Haversine formula and a mean Earth radius of **6,371 km**. This is used both to calculate flight-leg costs and to estimate the remaining distance to the destination.

The notebook discusses why this heuristic is admissible and consistent for the distance-based graph model.

## How to Run

1. Clone or download this repository.
2. Make sure `flight_route_search_v11.ipynb` is in the project directory.
3. Make sure `airports.dat` and `routes.dat` are in the same directory as the notebook. If they are absent, the notebook setup cell attempts to download them.
4. Install the required packages:

   ```bash
   python -m pip install numpy matplotlib notebook
   ```

5. Start Jupyter:

   ```bash
   jupyter notebook
   ```

6. Open `flight_route_search_v11.ipynb`.
7. Run the notebook cells from top to bottom.

The notebook constructs the graph, runs both search algorithms, prints the discovered itineraries and performance metrics, and generates the comparison figures.

## Notes and Limitations

- This is an academic search-algorithm experiment, not a live flight booking or airline scheduling system.
- A route edge represents a dataset connection; the project does not verify current flight schedules, operating status, ticket prices, travel restrictions or passenger connections.
- Route distance is estimated from airport coordinates using great-circle distance for each edge.
- DFS is depth-bounded in this implementation, so its result depends on graph adjacency ordering and the selected depth limit.
- Benchmark results should be taken from a fresh execution of the notebook. Different dataset versions, execution environments or code revisions may produce different results.
